# MVP仕様

## 対象ユーザー

- 筋トレ初心者
- 自宅トレ中心の人
- 食事管理が苦手な人

## MVPで実装する機能

- ユーザー登録・ログイン
- 初期設定
- 体重記録
- 食事記録
- 筋トレ記録
- 今日の振り返り
- ダミーの商品表示

## MVPで重視する追加要素

- 筋トレ記録時に前回記録を表示する
- 過去日付の記録を簡単に入力できる
- タイマーや写真投稿は強制しない
- 分析は最初は簡易でよい
- 今日の記録から明日やることを3つ出す
- 商品提案は記録内容に連動させる

## MVPでは実装しない機能

- 本番AI連携
- Stripe決済
- 広告
- 本番アフィリエイト
- 画像解析
- バーコード読み取り
- SNS
